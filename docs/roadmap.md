# Roadmap

## Current

- Android touch controller
- USB tethering / RNDIS transport
- Fixed 13-byte UDP protocol
- 250 Hz heartbeat + state-change wake-up
- Windows XInput virtual controller through ViGEm
- PS-style face buttons and layout
- Saved layout positions
- Reset-to-default layout
- Disconnect-safe Android sender

## Candidate next steps

- Safer configurable server IP in the Android UI
- Connection status indicator
- Optional Windows watchdog that resets input after a timeout
- Layout resize handles
- Multiple saved controller profiles
- More polished gaming theme and branding
- Release automation for APK and Windows server
